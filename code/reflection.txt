This assignment was very similar to the second assignment, but the addition of Streamlit made it more challenging. Even though the difficulty was greater, I was still able to work through the problems and complete the assignment. One useful lesson I learned from debugging was how important it is to understand the steps in a data pipeline and how each function passes information to the next. For example, the build_payroll() function cleans the timesheet and employee data, merges the information, and then calculates gross_pay and pay_type before the Streamlit app displays the results. In the future, I would like to practice tracing data through each step of a pipeline and reading test errors more carefully. This would help me identify which function is causing a problem and understand how to fix it more efficiently.
